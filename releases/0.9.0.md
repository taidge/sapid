# Sapid 0.9.0

Sapid uses Glory 0.9 and its coordinated native engine releases. Native scroll
areas preserve the finger gesture's axis during momentum and allow a physical
mouse wheel to scroll both axes.

The widget catalogue adds an international telephone editor, virtualized flat
combobox results, an animated segmented-control indicator and keyboard resizing
examples for AppShell. Showcase previews can also run in a native Wry window.
